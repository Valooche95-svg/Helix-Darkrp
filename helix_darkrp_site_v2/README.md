# Hélix Roleplay — Site DarkRP V2

Site statique complet pour serveur Garry's Mod DarkRP.

## Fichiers
- `index.html` : contenu du site
- `assets/style.css` : design / couleurs
- `assets/script.js` : menu, animations, bouton copier IP, métiers interactifs

## À modifier rapidement
Dans `index.html`, cherche et remplace :
- `HÉLIX ROLEPLAY` par le nom de ton serveur
- `TON.IP.SERVEUR:27015` par ton IP
- `https://discord.gg/tondiscord` par ton lien Discord
- Les prix/boutique par ton vrai lien

## Hébergement gratuit
Compatible Cloudflare Pages, GitHub Pages, Netlify.
Build command : vide
Output directory : `/`
